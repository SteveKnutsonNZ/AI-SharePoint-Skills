To create a Skill you must have an M365 Copilot License.

To add a Skill to SharePoint do the following:
1. In Site Collection Features enable the Agent Assets feature
2. Navigate to the Skills folder in the Agent Assets Library
3. Create a Folder with the Skill Name "Board-meeting-prep"
4. Save Skills.md into the folder

To use the Skill
1. Open a new AI chat in the SharePoint site
2. Type "--Agent-skills" to get a list of Agent Skills
3. This agent starts when you enter the prompt "prep for the board meeting"


NOTE:
- The GUID's for List and Library ID's in Skills.md should be updated with the values from your site
